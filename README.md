# Mechanical Design

**MREN 403 | Autonomous Snow-Clearing Robot for Kingston City Sidewalks**

This repository contains the mechanical design files and supporting engineering documentation for our autonomous snow-clearing robot. It serves as the central location for SolidWorks models, engineering drawings, design calculations, and preliminary concepts.

## Repository Structure

| Folder | Description |
|---|---|
| `CAD/` | SolidWorks parts, assemblies, and engineering drawings. |
| `Design-Calculations/` | Supporting engineering calculations, component sizing, and mechanical analysis. |
| `Concept-Development/` | Preliminary sketches, design concepts, and reference material. |
| `Documentation/` | Technical documentation and design decisions. |
| `Images/` | CAD renderings, diagrams, and project visuals. |

## Getting Started

- **CAD Models:** Navigate to `CAD/` to access mechanical components and assemblies.
- **Design Calculations:** Navigate to `Design-Calculations/` for supporting engineering analysis.
- **Concept Development:** Navigate to `Concept-Development/` to view preliminary designs and sketches.

SolidWorks files should be opened with their associated part and assembly references to ensure proper functionality.
